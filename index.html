Stripe Takings

Balance, payments and payouts across every Stripe account you check. Keys go straight from this browser to Stripe over HTTPS — no server in between, and nothing is saved anywhere.

Add as many accounts as you like — each gets its own card. Use restricted keys (rk_live_…, read access to Balance, Charges, Payouts and Account): this page only ever reads, and a read-only key can't move money if it leaks.
