Stripe Operations

Everything a read-only key can tell you about an account: money, risk, customers and timing. Keys go straight from this browser to Stripe — no server in between. A key stays in this page's memory so you can refresh an account, and is gone the moment you close the tab or press Clear all. Nothing is ever written to disk.

Use restricted keys (rk_live_…). This page only reads. Each section needs its own read permission on the key — anything not granted is shown as locked rather than failing the page. Grant: Balance, Charges, Payouts, Account, Disputes, Refunds, Customers, Checkout Sessions, Subscriptions, Invoices, Events and Radar.
